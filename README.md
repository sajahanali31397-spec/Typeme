## 🚀 How to Publish on GitHub Pages (In 3 Minutes)

You can upload all files directly through your browser:

1. Log into **[github.com](https://github.com)** and click **New Repository**.
2. Name it `typeme` (or your preferred name), set to **Public**, and click **Create repository**.
3. Click **"uploading an existing file"**.
4. Drag and drop the following files/folders from your project folder:
   - `index.html`
   - `manifest.json`
   - `README.md`
   - `assets/creator.png`
   - `google-apps-script/Code.gs`
5. Click **Commit changes**.
6. Go to **Settings** > **Pages** > Select branch `main` and folder `/ (root)` > Click **Save**.
7. Your website is live worldwide with free HTTPS!
